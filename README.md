# fplpro-data

Daily, derived Premier League match probabilities for the FPL Pro app.

- Source: The Odds API (free Starter plan), fetched once a day by GitHub Actions.
- Published: only derived numbers per fixture (win/draw/loss probability, expected goals, clean-sheet probability). No raw bookmaker prices, no API key.
- Hard limits keep usage far below the free plan's 500 monthly credits.
